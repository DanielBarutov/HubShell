HubShell — установка на Windows 10/11 x64

ЧТО ЗАПУСКАТЬ
HubShell.exe — клиент: окно входа и игровой сеанс.
HubShell.Watchdog.exe — фоновая служба: следит за клиентом и выполняет обновления.
Оба EXE нужны. Службу вручную двойным щелчком не запускайте.

УСТАНОВКА ИЛИ ОБНОВЛЕНИЕ
1. Завершите игровой сеанс. В PowerShell от администратора остановите службу:
   Get-Service HubShell.Watchdog -ErrorAction SilentlyContinue | Stop-Service
   После этого закройте HubShell.exe.
2. Распакуйте комплект в C:\GameClub с заменой файлов от администратора.
   Сохраните существующий server.ini и файлы данных/идентичности этого ПК.
   При первой установке скопируйте server.ini.example в server.ini
   и укажите адреса своего сервера и публичный ключ V2 snapshot.
3. В C:\GameClub запустите start-service.cmd от имени администратора.
   Он устанавливает/обновляет и запускает службу. Клиент запускается службой.
   Для ручного запуска клиента используйте HubShell.exe.

Автообновления требуют отдельной настройки службы для каждого ПК:
индивидуальной регистрации, адреса backend и доверенного ключа подписи выпуска.
Обычный start-service.cmd без этих данных настраивает только восстановление клиента.
Не копируйте данные регистрации и сеансов с другого ПК.

Первую установку проверьте на одном свободном ПК. Windows-пилот ещё не выполнен.
