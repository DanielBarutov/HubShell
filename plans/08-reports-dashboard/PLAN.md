# План 08 — Reports / Dashboard

Статус: `in_progress`  
Приоритет: `P1`  
Владелец: `backend/`  
Зависимости: `06-sessions`, `07-billing`, `04-auth-security`

## Цель

Дать web-dashboard и внутренним клиентам честные read-only показатели клуба на
основе сохранённых бизнес-операций. Первый срез — выручка по заданному периоду;
кассовые смены, закрытие дня и расширенная аналитика остаются отдельными
вертикалями.

## Входит в первый срез

- сумма сохранённых `SessionCharge` в целых копейках;
- количество проведённых списаний;
- фильтр по UTC-периоду `[start_at, end_at)`;
- HTTP BFF и versioned gRPC read contract;
- явный empty state и отсутствие фиктивных значений в web.

## Не входит

- открытие/закрытие кассовой смены;
- наличные, возвраты, эквайринг и сверка внешних платежей;
- произвольные аналитические SQL-запросы из frontend;
- агрегация PII и детализация персональных данных в отчёте.

## Критерии готовности первого среза

- сумма строится только из сохранённых `SessionCharge`;
- деньги не используют `float`;
- запросы защищены JWT permission `dashboard.read`;
- период и границы явно передаются в контракте;
- dashboard не показывает выдуманную выручку в live-режиме.
